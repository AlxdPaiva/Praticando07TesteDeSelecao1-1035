Timelimit: 1
Leia 4 valores inteiros A, B, C e D. A seguir, se B for maior do que C e se D for maior do que A, e a soma de C com D for maior que a soma de A e B e se C e D, ambos, forem positivos e se a variável A for par escrever a mensagem "Valores aceitos", senão escrever "Valores nao aceitos".

Entrada
Quatro números inteiros A, B, C e D.

Saída
Mostre a respectiva mensagem após a validação dos valores.

Esse programa me tomou preciosos minutos pois, no netbeans, ele rodou perfeitamente, porém na plataforma do beecrowd, ele acusou 20% de erro. Como é uma lógica simples, revisei várias vezes e não consegui determinar o erro. Caso vc encontre, abra uma issue para me ajudar a entender. Obrigado!
